Usa el subagente `arquitecto` para escribir una spec nueva a partir de este requisito:

$ARGUMENTS

1. Busca el número más alto en `specs/` y usa el siguiente (formato `NNN`, con tres dígitos).
2. Crea `specs/NNN-<nombre-corto>.md` con la plantilla `specs/000-plantilla.md`.
3. Muéstrame los criterios de aceptación y las preguntas abiertas. No sigas a `/plan` hasta que yo apruebe.
